# UX/UI и функциональный аудит Screendance App

Дата: 23 сентября 2026. Область: checkout на момент аудита, установленное приложение 1.4.0 и локальный рендер отдельных окон. Ниже сохранены исходные наблюдения; статус реализации версии 1.5.0 указан в [заметках к выпуску](../../releases/v1.5.0.md).

## Результат

Приоритетная последовательность: восстановить отдельное окно выбора источника; завершить и проверять регистрацию локалей; исправить управление редактором с клавиатуры; сделать удаление пресетов обратимым; затем переработать путь экспорта. Оценка по десяти эвристикам Нильсена — **23/40** (3, 2, 3, 2, 2, 2, 3, 2, 2, 2). Запись и статусы сохранения стали понятнее после пакета исправлений 25 августа, но доступность редактора и экспорт остаются слабыми местами.

## Надёжность экспорта: следующая архитектурная задача

Место сохранения выбирается после завершения рендера: `src/components/video-editor/VideoEditor.tsx:4474-4511`, затем `electron/ipc/register/export.ts:1289-1318` показывает save dialog. Пользователь узнаёт о недоступной папке или отменяет сохранение после затратного кодирования. `handleCancelExport` сразу сообщает об отмене и убирает прогресс (`VideoEditor.tsx:4956-4966`), хотя современный exporter отправляет запросы отмены native-сессиям без ожидания ответа (`src/lib/exporter/modernVideoExporter.ts:3872-3894`). Это **риск гонок и потерянного состояния**, не воспроизведённая потеря файла.

Рекомендуемая реализация: выбрать destination и проверить доступное место/кодек до рендера; хранить export job и фазу в main process; подтверждать отмену после остановки, cleanup и сохранения результата; оставить прогресс доступным при закрытии popover. Проверить отказ диска, отмену на каждой фазе, перезапуск, отменённый save dialog и повторное сохранение. При изменении ProRes alpha соблюдать guardrail в корневом `AGENTS.md`, включая ручную проверку Quick Look/Finder.

## Проверки и границы выводов

- `npx tsc --noEmit` — успешно.
- `npm test` — успешно; unit-тесты не покрывают автономный маршрут `source-selector`.
- `npm run i18n:check` — успешно, но имеет описанный выше пробел в проверке зарегистрированных языков.
- `PACKAGED_SMOKE_ROOT=release/mac-arm64 PACKAGED_SMOKE_ARCH_TAGS=darwin-arm64 npm run smoke:packaged-binaries` — успешно.
- `PACKAGED_SMOKE_ROOT=release/mac PACKAGED_SMOKE_ARCH_TAGS=darwin-x64 npm run smoke:packaged-binaries` — успешно.
- `npm run lint` — не проходит: 312 ошибок и 25 предупреждений Biome, в основном накопленные форматирование и порядок импортов; это отдельный технический долг. Полезно сначала зафиксировать baseline, затем сделать линтер обязательным для новых изменений.
- Impeccable detector нашёл два низкозначимых предупреждения: спиннер `SourceSelector.tsx:136` (ложное срабатывание) и градиент индикатора загрузки `PlaybackCursor.tsx:115`.
- Установленное приложение 1.4.0 проверено через macOS accessibility-дерево. HUD исключён из screen capture, поэтому его screenshot белый; визуальный рендер редактора и экспорта в установленной сборке не проверен. Локальный браузер без Electron preload непригоден для проверки этих двух окон; подтверждённый сбой `source-selector` происходит раньше вызовов preload.
- Полную запись и медиаэкспорт на пользовательских файлах в этом аудите не запускали. Архитектурные риски экспорта требуют отдельных сценарных и fault-injection тестов.
