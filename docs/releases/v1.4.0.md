# Screendance App 1.4.0

<!-- locally-notarized-release -->

This release makes repeatable video production much faster: editor templates
now preserve the full presentation and export setup, and the last selected
template is applied automatically to every new recording and imported video.

## Highlights

- Templates preserve cursor visibility, padding, main-video crop, aspect ratio,
  output format, transparent/GIF options and caption styling.
- Webcam size, shape, position and other reusable layout settings are restored
  without copying camera media from another project.
- Default zoom-creation behavior is included in templates.
- Existing `.scrdance` and `.recordly` projects remain authoritative and are not
  overwritten by the last-used template.
- Native recordings still suppress a duplicate overlay cursor when the session
  requires it.

## macOS downloads

- Apple Silicon: `Screendance-App-arm64.dmg`
- Intel: `Screendance-App-x64.dmg`

Both builds target macOS 14 or newer, are signed with the Screendance Developer
ID certificate, notarized by Apple and stapled for offline verification.

The release also includes ZIP archives for automatic updates, blockmaps,
`latest-mac.yml` and `SHA256SUMS.txt` for integrity verification.
