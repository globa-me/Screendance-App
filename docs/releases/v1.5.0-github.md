# Screendance App 1.5.0

<!-- locally-notarized-release -->

This release improves source selection, keyboard access and video export.

## Highlights

- Fixed the standalone source picker, added thumbnail fallbacks and made
  source names easier for screen readers to announce.
- Enabled Russian in the language menu and strengthened locale checks.
- Added visible keyboard focus and timeline seeking with arrow keys, Shift,
  Home and End.
- Added Undo for deleted presets and custom wallpapers.
- Simplified export settings. You now choose the destination before rendering,
  see progress from the toolbar and get safer cancellation and file replacement.
- Improved recording error messages and ProRes BT.709 color metadata.

## macOS downloads

- Apple Silicon: [Screendance-App-arm64.dmg](https://github.com/globa-me/Screendance-App/releases/download/v1.5.0/Screendance-App-arm64.dmg)
- Intel: [Screendance-App-x64.dmg](https://github.com/globa-me/Screendance-App/releases/download/v1.5.0/Screendance-App-x64.dmg)

Both builds target macOS 14 or newer. The apps and DMGs are signed, notarized
by Apple and stapled. The Apple Silicon build was launched under macOS
quarantine on a Mac, then used to record the screen and export a test video.
The Intel package passed signature, Gatekeeper and binary checks; a physical
Intel GUI test has not been completed.

ZIP archives for automatic updates, blockmaps, `latest-mac.yml` and
`SHA256SUMS.txt` are included. Full validation details are in
[the release record](https://github.com/globa-me/Screendance-App/blob/v1.5.0/docs/releases/v1.5.0.md).
