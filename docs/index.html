Screendance App — macOS-форк Recordly для записи экрана и быстрого монтажа: ScreenCaptureKit, зумы, курсор, веб-камера, оформление кадра и экспорт.

Открыть GitHubГотовые сборки

Запись и звук

Дисплей или окно, системный звук, микрофон, веб-камера и нативный захват ScreenCaptureKit. Во время записи видны активные источники и уровни звука.

Монтаж и экспорт

Таймлайн, обрезка, зумы, аннотации, курсор, фоны и веб-камера. Экспортируйте MP4, GIF, прозрачный WebM или ProRes 4444.

Пока нет опубликованного релиза. Когда сборка появится, скачивайте её только из GitHub Releases. Не отключайте защиту macOS ради файлов из неизвестных источников.

Установка готового приложения

  1. Скачайте .dmg для arm64 из Releases.
  2. Перетащите приложение в Applications.
  3. При блокировке: System Settings → Privacy & Security → Open Anyway, затем Open.
  4. Разрешите Screen & System Audio Recording и Accessibility; для камеры и микрофона — соответствующие разрешения.

Сборка на своём Mac

Установите Xcode Command Line Tools и Node.js 22 LTS, затем:

git clone https://github.com/globa-me/Screendance-App.git
cd Screendance-App
git switch screendance/macos-apple-silicon
npm ci
npm run build:mac

Результат: release/Screendance App-arm64.dmg.
